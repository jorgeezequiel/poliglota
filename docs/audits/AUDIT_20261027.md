## 4. GitHub Actions Workflow (CI/CD)

### Arquivo: `.github/workflows/ci.yml`

**Status**: ✅ **ATUALIZADO E PRONTO**

**Alterações**:
- Desacoplado de 1 job (`tests`) para 4 jobs independentes
- Adicionado cache de modelos Hugging Face (HF Hub) com chaves por OS/Python
- Adicionado timeouts apropriados (10/15/30/60 min)
- Adicionado job `summary` para compilação de resultados

### Jobs

#### 1. `quality` (10 min)
- **Descrição**: Lint, formatação, verificação de versão
- **Sistema**: Ubuntu, Python 3.13
- **Trigger**: Todo push/PR
- **Comandos**:
  - `ruff check poliglota tests`
  - `ruff format --check poliglota tests`
  - `pytest tests/test_version_consistency.py -v`
- **Saída**: Nenhuma (validação somente)

#### 2. `unit-tests` (15 min, 9 jobs)
- **Descrição**: Testes unitários isolados (sem PyTorch)
- **Matriz**: Ubuntu/Windows/macOS × Python 3.11/3.12/3.13 (9 combinações)
- **Dependências**: `[dev]` apenas
- **Comando**: `pytest -q -m unit --junitxml=reports/test-results/junit-unit-*.xml`
- **Cache**: pip
- **Saída**: Artefatos JUnit XML (7 dias retenção)

#### 3. `integration-cpu` (30 min, 9 jobs)
- **Descrição**: Testes de integração com PyTorch em CPU
- **Matriz**: Ubuntu/Windows/macOS × Python 3.11/3.12/3.13 (9 combinações)
- **Dependências**: `[dev,gpu]` (PyTorch/Transformers)
- **Comando**: `pytest -q -m "not gpu" --junitxml=reports/test-results/junit-integration-cpu-*.xml`
- **Env**: `POLIGLOTA_TEST_CPU_ONLY=1`, `HF_HUB_OFFLINE=0`
- **Cache**: pip + Hugging Face Hub (~/.cache/huggingface)
- **Saída**: Artefatos JUnit XML (7 dias retenção)

#### 4. `integration-gpu` (60 min, 1 job)
- **Descrição**: Testes de integração com GPU/CUDA
- **Configuração**: self-hosted com labels `gpu`, `cuda`
- **Trigger**: `push` para `main` apenas (não em PRs, não em `develop`)
- **Dependências**: `[dev,gpu]`
- **Comando**: `pytest -q -m gpu --junitxml=reports/test-results/junit-integration-gpu-*.xml`
- **Env**: `HF_HUB_OFFLINE=0`, `POLIGLOTA_DEVICE=auto`
- **Cache**: pip + Hugging Face Hub (chave GPU)
- **Saída**: Artefatos JUnit XML (7 dias retenção)

#### 5. `summary` (resumo)
- **Descrição**: Compilação de resultados de todos os jobs
- **Dependências**: quality, unit-tests, integration-cpu
- **Ação**: Parse JUnit XMLs, soma totais, escreve em GitHub Step Summary
- **Falha Se**: Total = 0 OU falhas > 0 OU erros > 0

### Matriz Completa de Testes

| Job | OS | Python | Timeout | Deps | Tests |
|-----|----|---------|----|---|---|
| quality | Ubuntu | 3.13 | 10 min | [dev] | quality (lint/format/version) |
| unit-tests | Ubuntu | 3.11/3.12/3.13 | 15 min | [dev] | unit-tests (3×3=9 jobs) |
| unit-tests | Windows | 3.11/3.12/3.13 | 15 min | [dev] | |
| unit-tests | macOS | 3.11/3.12/3.13 | 15 min | [dev] | |
| integration-cpu | Ubuntu | 3.11/3.12/3.13 | 30 min | [dev,gpu] | integration-cpu (3×3=9 jobs) |
| integration-cpu | Windows | 3.11/3.12/3.13 | 30 min | [dev,gpu] | |
| integration-cpu | macOS | 3.11/3.12/3.13 | 30 min | [dev,gpu] | |
| integration-gpu | self-hosted | 3.13 | 60 min | [dev,gpu] | integration-gpu (condicional main) |
| summary | Ubuntu | 3.13 | 10 min | none | Compile results |

**Total**: 1 + 9 + 9 + 1 + 1 = **21 jobs paralelos** (em caso de push para `main`); **19 jobs** em PRs (sem GPU).

### Cache de Modelos Hugging Face

**Estratégia**:
- Chave primária: `hf-models-{cpu|gpu}-{OS}-py{VERSION}`
- Fallback: `hf-models-{cpu|gpu}-{OS}-`, depois `hf-models-`
- Caminho: `~/.cache/huggingface` (padrão HF Hub)

**Resultado**: Primeira execução faz download (~10 min CPU, ~20 min GPU); execuções subsequentes restauram cache (~1-2 min).

## 9. Limitações Conhecidas

1. **Sem Pre-staging de Modelos**: Primeira execução de `integration-cpu` faz download (~10 min); subsequentes usam cache.
2. **GPU Runner Opcional**: `integration-gpu` requer self-hosted com CUDA; pode ser pulado se não configurado.
3. **Sem Compilação de Wheels**: Workflow não publica distribuições (wheels, sdists).
4. **CI não Instala GPU em unit-tests**: `[dev]` apenas, evitando 2+ GB de PyTorch por build; testes GPU marcados `@pytest.mark.gpu` e pulados.
