# Branding do Poliglota

Este diretório guarda a identidade visual oficial do Poliglota, baseada na variante original criada no Google Stitch.

## Arquivos

- `original/poliglota-matte-flat-logo.png` — asset original exportado do projeto Stitch, preservado fielmente.
- `poliglota-social-preview.png` — versão preparada para apresentação pública do repositório no GitHub.

## Uso

- README do repositório: usa a imagem original em escala apropriada.
- apresentação pública do GitHub: use a social preview preparada.

## Preservação

A identidade visual foi mantida fiel ao original. Não foram realizadas alterações de cor, composição, proporção ou texto.
